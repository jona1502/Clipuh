# clipuh UI Icons

20 separate transparent PNG icons from the approved generated icon sheet.

Each file is 250 × 250 px, retaining the original dark rounded button tile and its icon.
The assets are raster graphics, not SVG/vector icons.

## Notes

- The generated sprites are decorative icon-button tiles, not bare white glyphs.
- For GPUI controls that already draw a button background, consider using Lucide/SVG glyphs instead to avoid double backgrounds.
- Source artwork is included as `icon-sheet-original.png`.
